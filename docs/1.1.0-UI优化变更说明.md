## 三、设计规范（Spec）对照

- 颜色：全部经 `DeployXColors`（success/error/warning/secondary/link/accent/border）。✅
- 字体：注释 `JBUI.Fonts.smallFont()`，未写死字体名。✅
- 间距：内容 12、组间 12、对话框最小宽 480，均经 `JBUI.scale`。✅
- 主次：每视图一个主按钮（部署 ▾）。✅
- 错误不只靠颜色：缺项/未选服务器/历史状态均有文字。✅
- 键盘：Enter/Esc（DialogWrapper）、Shift+Enter 浏览、对话框键入路由搜索。✅
- 图标按钮 tooltip / accessibleName：PathField 设置 accessibleDescription；其他沿用原 tooltip。🟡

## 四、需要在 runIde 中人工核对

1. 新 / 经典 UI 下内容页签位置；暗 / 亮 / 高对比主题实时切换颜色。
2. 工具窗口宽 320 / 400 / 560：底部状态区与两个拆分按钮不被挤掉。
3. 「部署 ▾」是否呈主色；选「快速推送」后主体是否记住（重启 IDE 后仍保持）。
4. 状态区：执行后结果行、「日志」「报告」「关闭」；完成通知动作。
5. 部署目标对话框：`lib` / `lib2` / 无映射 / 多选交集四种情况；Enter 确认、未选时按钮不可用。
6. 历史页过滤计数、回滚原因提示；回滚确认框 Enter 默认为取消。
7. 中英文切换后页签标题、按钮、摘要文案刷新。

- 回滚确认框：展示将在服务器上执行的命令原文、此后被覆盖的部署次数；新增「回滚前先备份当前状态」（默认勾选）与「回滚后执行上传后命令」选项；回滚进度框保留。

- 第二轮：历史详情区、服务器—映射一体对话框（保留双击确认）、脚本页卡片+行内详情、任务结果按 success 标志判定（#28）。
